# Project 3 - Data Management

## Setup

1. Start Container

   ```bash
   docker compose up -d
   ```

## Python Environment

1. Virtual environment

   ```bash
   python -m venv .venv
   ```

2. Aktivasi

   ```bash
   # Windows (PowerShell)
   .\.venv\Scripts\Activate.ps1

   # macOS / Linux
   source .venv/bin/activate
   ```

3. Install dependencies

   ```bash
   pip install -r requirements.txt
   ```
